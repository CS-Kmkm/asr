## Product behavior

The stop pipeline owns the finalized WAV after capture. If a Dictate/Translate take loses its expected preview owner, the pipeline keeps that WAV and uses whole-take recognition. A successful recognition bypasses automatic routing and delivery and publishes the raw transcript in the app. Edit and Ask keep their independent target sessions and continue mode delivery when only the recognition-only task fails. The recovery branch reserves a completion job before publishing. History records the raw text and retains the audio according to current policy in that job, outside the lifecycle mutex. The row uses the faithful mode so explicit History actions can operate on the raw transcript. The operation lifecycle arbitrates cancellation before the recovery commit. A later recognition failure still goes through the existing failed-take policy where the mode supports retry.

The JSONL reader reports EOF as a crash immediately. Each request write and flush has a five-second deadline, separate from model load and transcription deadlines. A partial write can invalidate the stream, so the existing reset path terminates and reaps the process. Graceful shutdown waits for process exit after a successful shutdown reply, and terminates on a failed reply or exit wait.

## Wave A recording durability

- Normal stop flushes the remaining samples to the checkpoint before recognition, including when stop precedes the first periodic write. A retained take consumes its replay token in the History transaction. Cancellation and intentional rejection consume the token before unlinking. Cancellation does so before waiting for device teardown.
- Delete all and retention withdrawal advance the privacy epoch and purge older spool files. Startup retries stale cleanup and only reads the prefix of complete, checksummed PCM frames. An append failure preserves the prior prefix.
- The replacement microphone buffers up to the three-second adoption window. Live preview and streaming recognition wait through that window. The callback reuses a mono buffer, and the take's retained sample count is bounded by the existing 15-minute limit at its original sample rate.
- Regression fixtures cover durable replay and cancellation, stale epochs, torn frames, delayed and late reopen results, and the sample cap. Real microphone disconnect and process-exit behavior still need a desktop check.
