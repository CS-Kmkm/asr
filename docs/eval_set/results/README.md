# ベンチマーク結果の読み方

モデルへ渡す日本語モデル比較のスコアは、まず[集計要約](issue-89-qwen3-context-v1.json)を使ってください。
列名を共有する配列で、モデル・実行環境・実デバイス、raw/正規化CER、ドメイン別CER、warm p50/p95、ロード、失敗件数、GPUメモリを記録しています。
CERの単位は%、時間はms、GPUメモリはMiBです。`null`は未記録で、0とは異なります。

200音声の日本語評価で、warm反復は独立な音声件数に含めません。時間はworkerのリクエスト／応答で、デスクトップアプリの停止→挿入時間ではありません。
GPUメモリは他アプリを含むデバイス全体の観測値です。日本語以外や専門語に対する優位性を、このスコアだけから判断しないでください。

[詳細JSON](issue-89-qwen3-holdout-v1.json)はそのまま保存しています。
時間分布・誤り数・ハッシュなどを調べるときに読み、通常の比較では要約を使います。
[生成コマンドと対応形式](../public_datasets.md)も参照してください。
