# 日本語読み上げ台本

本台本は ASR 評価セット固定台本（日本語）である。
**一度固定した台本は変更禁止。** 変更すると過去計測との比較が不能になる。
台本 ID とファイル命名規則は `README.md` を参照。

---

## 読み方の規約

- 数字は原則として日本語読み（例: 「12GB」は「じゅうにぎがばいと」）。ただし各台本に「読み上げ表記」として記す文字列が正解文（references.json）と一致する表記であるため、**正解文をそのまま読み上げること**。
- ファイルパス・コマンド名は正解文に書かれたカタカナまたは日本語読み表記で発話する（例: `asr_worker` は「エーエスアールワーカー」ではなく正解文の表記に従う）。
- 句読点は発話しない（スコアリング時に除去される）。
- 台本ごとに **想定秒数** を記す。これは標準的な日本語読み上げ速度（約7〜8文字/秒）を基準とした目安である。
