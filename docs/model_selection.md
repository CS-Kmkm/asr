# 音声認識モデルの手動選択

モデルは「設定 → モデル」で選び、「モデルを読み込む」で準備します。
録音中の自動切り替えは行いません。既定モデルは変更していません。

| 用途・条件 | 手動選択 | 判断の根拠・注意 |
|---|---|---|
| WindowsのGPUで日常的な日本語入力 | 日本語モデル（Vulkan）／Haas-ja-v1.0 | RTX 3060・日本語200音声では正規化CER 4.32%、warm p50 65 ms。比較した構成で精度と処理時間の両方が良好 |
| 日本語以外の認識言語も指定する | faster-whisper、またはQwen3 1.7B | 言語対応に基づく選択。今回の日本語評価だけでは、他言語での優劣は判断できない |
| 辞書を認識モデルの文脈として渡す機能が必要 | Qwen3 1.7B／speech.cpp（Vulkan） | 文脈入力に対応。ただし無関係な辞書語を渡した比較ではCERが悪化した。用途に合う語で別途確認する |
| GPUを使わずWindows CPUで動かす | faster-whisper、またはReazonSpeech k2／ONNX Runtime／CPUのみ | CPU対応という機能上の選択。CPU同士の200件比較による順位は未測定 |

Qwen3 0.6Bは、今回の日本語入力向けの推奨候補にはしません。
1.7Bのtransformers版は別構成であり、speech.cpp版の測定値を流用しないでください。

設定時はカタログの対応言語・実行環境・ライセンス・取得容量と、読み込み後の実デバイスを確認してください。
speech.cppのGPUはVulkanです。CUDAの利用可否だけで速度を判断しないでください。
ONNX RuntimeはCPU/CUDAを選択できます。transformersの自動選択とCUDAのみではCUDA GPUが必要で、暗黙にCPUへ再試行しません。
自動音声モードとの依存関係の競合は設定画面で制限されます。ReazonSpeechをCPUのみにした場合を除き、新しい2ランタイムと同時には使えません。

この数値は音声認識リクエストの処理時間で、録音停止から入力欄への挿入までの時間ではありません。
FLEURS/JVNVの固定音声による比較で、自然な会話・小声・技術語を網羅した実利用評価ではありません。
GPUメモリの観測値には他アプリも含まれます。メモリの空きが足りない場合、別モデルやクラウドへ自動移行しません。

比較条件・ドメイン別スコアは[小さな集計要約](eval_set/results/issue-89-qwen3-context-v1.json)、
詳細は[元の結果](eval_set/results/issue-89-qwen3-holdout-v1.json)を参照してください。
stateful streamingは[#82](https://github.com/CS-Kmkm/asr/issues/82)の別機能で、区間ごとの増分確定とは区別します。
